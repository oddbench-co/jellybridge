About

Built by people who love open media.

JellyBridge is an independent, open source project by Oddbench. It exists to give Jellyfin users a fast, lightweight and beautiful native desktop experience.

JellyBridge started from a simple wish: the Jellyfin web app's interface, without the browser around it. It is written in Rust, draws its own interface and plays your files through mpv, so it starts quickly, stays light and never makes your server transcode.

The source code, the issue tracker and every release are on GitHub. JellyBridge is not affiliated with the Jellyfin project; it is a client for it, built with respect for what the Jellyfin community has made.
